# NT42-project

Personal project for NT42 prenatal care app

\# NT+ Welcome and Login App



An Android UI prototype built with Kotlin and Jetpack Compose for the NT+ welcome and login screens, using the Figma design as a reference.



\## Implemented Features



\- Welcome screen with the NT+ logo and Login/Register buttons.

\- Login screen with email and password fields.

\- Password visibility toggle.

\- Basic validation for empty fields and invalid email addresses.

\- Forgot Password link.

\- Apple, Google, and Facebook buttons with exported Figma logos.

\- Navigation between Welcome, Login, and a Register placeholder.

\- Back navigation to the Welcome screen.



\## How to Run



1\. Clone or download this repository.

2\. Open the NT42-project folder in Android Studio.

3\. Allow Gradle to sync.

4\. Select an Android emulator or connected Android device.

5\. Run the app configuration.



\## Current Limitations



This project implements the user interface and basic navigation.

Authentication, social login, and password recovery are not connected

to backend services. Registration currently displays a placeholder screen.



\## Manual Checks



Before submitting changes, verify that:



\- The app builds and launches.

\- Login opens from the Welcome screen.

\- Register opens the placeholder screen.

\- Back navigation returns to Welcome.

\- Email and password fields accept input.

\- Show/Hide toggles password visibility.

\- Empty fields and invalid emails display validation messages.

\- All three social login logos appear correctly.
